# 책스캔 (Android)

책을 사진으로 찍어 **통합독서분석(util)** 에 넣을 자료를 만드는 앱.
페이지 윤곽을 실시간으로 찾아 **지금 찍어도 되는 상태인지** 알려 주고, 조건이 맞으면 자동으로 찍는다.

## 화면에서 보는 것

- 미리보기 위에 **인식된 페이지 윤곽**이 그려진다 — 조건이 다 맞으면 **초록**, 아니면 주황
- 점선 네모칸은 안내선 — 페이지로 이 안을 채우면 된다
- 위쪽에 지금 무엇이 부족한지 한 줄로 표시된다

| 항목 | 무엇을 보나 | 기준 |
|---|---|---|
| 윤곽 | 종이 네 귀퉁이가 잡히는가 | 사각형 검출 |
| 채움 | 페이지가 화면을 채우는가 | 화면의 40% 이상 |
| 초점 | 흔들리거나 초점이 나갔는가 | 라플라시안 분산 75 이상 |
| 밝기 | 너무 어둡거나 반사가 심한가 | 평균 밝기 55~228 |
| 각도 | 비스듬히 찍었는가 | 마주 보는 변 길이 차 24% 이하 |

## 조작

- **화면을 누르면** 그 자리에 초점·노출을 맞춘다
- 흐릿하면 페이지 가운데로 **자동 초점**을 다시 잡는다(2.2초 간격)
- **자동 촬영**이 켜져 있으면 조건이 0.8초 이상 유지될 때 스스로 찍는다
- **촬영** 버튼으로 직접 찍을 수도 있다
- **새 묶음**: 새 촬영 묶음(세션)을 시작한다
- **PDF**: 이번 묶음 사진을 PDF 한 권으로 만들어 **다운로드 폴더에 저장**하고 공유창을 띄운다

## 저장 위치

- 사진: `Android/data/com.bookscan.app/files/Pictures/<날짜_시간>/001.jpg …`
  (USB로 PC에 연결하면 그대로 꺼내갈 수 있다)
- PDF: `Download/책스캔/책스캔_<날짜_시간>.pdf`

## PC로 가져간 뒤

1. PDF를 PC로 옮긴다(USB·카톡·텔레그램 아무거나)
2. util 앱 → **글자평탄화인식**: 휜 글줄을 펴고 손가락·배경을 지운다
   (사진을 그대로 넣어도 되고, 이 PDF를 넣어도 된다)
3. util 앱 → **통합독서분석**: OCR·낭독·챕터별 텍스트 추출

## 빌드

로컬 안드로이드 스튜디오 없이 **GitHub Actions**로 APK를 만든다(킨들번역·티비위키와 같은 방식).

```bash
git remote add origin https://github.com/ndreamer-tech/bookscan.git
git push -u origin main
```

푸시하면 Actions가 돌아 `최신 APK` 릴리스에 `app-debug.apk`가 붙는다. 폰에서 그 파일을 내려받아 설치.

## 기술 메모

- CameraX(미리보기·분석·촬영) + OpenCV 4.10(윤곽 검출)
- 분석은 YUV의 Y면만 써서 4:3 저해상도로 돌리고, 촬영은 최대 화질(JPEG)
- 윤곽 검출: Otsu 이진화 → 최대 외곽선 → 사각형 근사(안 되면 최소외접 사각형)
- 초점 판정: 화면 가운데를 잘라 라플라시안 분산
